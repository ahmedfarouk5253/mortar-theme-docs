---
title: Performance tips
---

- Use images about 2400 px wide for full-width sections and about 1200 px for others. Mortar requests the right size for each screen.
- Add a separate mobile image to the hero and slideshow slides, so phones download a smaller image.
- Keep the first section (usually the hero) to one image. It loads first; everything below loads as customers scroll.
- Background videos and autoplay slideshows add weight. Use them where they matter most.
- Every app you install can add scripts to every page. Remove apps you don't use.
